데이터 삭제 요청

ThreadPilot은 언제든지 연결을 해제하거나 계정과 데이터의 삭제를 요청할 수 있습니다. 이 페이지는 삭제되는 데이터의 범위, 요청 방법, 처리 기간을 안내합니다.

1.요청 방법

아래 세 가지 방법 중 편한 것을 이용하시면 됩니다.

가. 앱에서 직접 — 가장 빠릅니다

  1. Threads 연결 해제ThreadPilot 설정 → 연결된 계정 → 연결 해제. 액세스 토큰이 즉시 폐기되고, 발행·댓글 수집이 중단됩니다.
  2. 계정 삭제ThreadPilot 설정 맨 아래 → 계정 및 데이터 삭제 요청. 로그인 정보와 서비스 이용 기록이 삭제됩니다.
  3. Threads 권한 제거Threads 앱 → 설정 → 웹사이트 권한에서 ThreadPilot을 제거하면, 서비스가 더 이상 계정에 접근할 수 없습니다.

나. 이메일로 요청

zilzil772@gmail.com 으로 아래 내용을 보내주세요. 본인 확인 후 처리합니다.

  • 제목: [ThreadPilot] 데이터 삭제 요청
  • 가입에 사용한 이메일 주소
  • 연결한 Threads 핸들(@아이디)
  • 삭제 범위: 연결 해제만 / 발행·댓글 기록 삭제 / 계정 전체 삭제

본인 확인을 위해 가입 이메일에서 요청해 주세요. 대리 요청의 경우 위임 사실을 확인할 수 있는 자료를 요청할 수 있습니다.

다. Meta(Threads)를 통한 삭제 요청

Meta를 통해 전달되는 데이터 삭제 요청도 동일하게 처리합니다. 서비스는 삭제 요청을 받으면 해당 Threads 사용자와 연결된 액세스 토큰과 서비스 데이터를 삭제하고, 처리 결과를 확인할 수 있는 확인 코드와 조회 주소를 안내합니다.

요청 처리 상태 조회

삭제 요청 시 안내받은 확인 코드를 입력하면 처리 상태를 확인할 수 있습니다.

2.삭제되는 데이터

데이터처리시점
Threads 액세스 토큰폐기·삭제(복구 불가)연결 해제 즉시
Threads 계정 연결 정보(사용자 ID, 핸들, 프로필 사진 URL, 권한 범위)삭제연결 해제 즉시
예약 문구·발행 기록·발행 로그삭제요청 후 30일 이내
수집한 댓글과 작성한 답글 기록삭제요청 후 30일 이내
회원 계정 정보(이메일, 이름, 비밀번호 해시, 업체명·업종)삭제계정 삭제 요청 후 30일 이내
자동화 설정(주제·말투·슬롯 등)삭제계정 삭제 요청 후 30일 이내
백업본에 남은 데이터백업 보관 주기에 따라 순차 삭제최대 30일

삭제되지 않는 것 — 이미 Threads에 게시된 글과 댓글은 회원의 Threads 계정에 남아 있으며, Threads 앱에서 직접 삭제해야 합니다. 전자상거래법에 따라 보존해야 하는 결제·계약 기록(5년)은 해당 기간 동안 보관합니다.

3.처리 기간과 결과 안내

  • 삭제 요청을 받으면 본인 확인 후 30일 이내에 처리를 완료하고, 등록된 이메일로 결과를 알립니다.
  • Threads 연결 해제와 토큰 폐기는 앱에서 즉시 처리됩니다.
  • Meta를 통해 접수된 요청은 확인 코드를 발급하고, 상태 조회 주소를 함께 안내합니다.
  • 처리 중 추가 확인이 필요한 경우(대리 요청, 계정 소유 확인 등) 이메일로 연락드릴 수 있습니다.
