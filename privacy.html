1.총칙

붐비다(이하 "운영사")는 「개인정보 보호법」 등 관련 법령을 준수하며, 이용자(이하 "회원")의 개인정보를 보호하기 위해 다음과 같이 개인정보처리방침(이하 "방침")을 수립·공개합니다.

이 방침은 운영사가 제공하는 ThreadPilot(스레드 예약 발행 및 댓글 자동 답글 서비스, 이하 "서비스")에 적용됩니다. 서비스는 회원이 자신의 Threads 계정을 연결하면, 회원이 정한 주제·말투·시간에 따라 글을 예약 발행하고 댓글에 답글을 다는 기능을 제공합니다.

운영사는 방침을 변경할 때 서비스 내 공지 또는 이 페이지를 통해 알립니다. 회원은 언제든지 이 페이지에서 방침의 최신 내용을 확인할 수 있습니다.

3.개인정보의 처리 목적

  2. 서비스 제공 — Threads 계정 연결, 예약 발행, AI 초안 생성, 댓글 수집과 자동 답글, 발행·답글 결과 안내

7.Threads(Meta) 연동 데이터

서비스는 Meta Platforms, Inc.의 Threads API를 사용합니다. 이 항목은 Meta 플랫폼 정책에 따라 Threads API로 받은 데이터의 처리 방식을 명시합니다.

  • 이용 목적의 제한 — Threads API로 받은 정보는 회원이 설정한 예약 발행과 댓글 자동 답글 기능을 제공하는 목적으로만 사용합니다.
  • 제3자 제공·판매 금지 — Threads API 데이터를 판매하거나, 광고 타기팅·신용평가·프로파일링 등 다른 목적으로 제공하지 않습니다.
  • 저장 범위 — 게시물 ID·퍼머링크, 댓글 내용, 계정 식별 정보만 저장합니다. 액세스 토큰은 암호화하여 저장하고, 발행·답글 직전에만 메모리에서 복호화합니다.
  • 권한 철회 — 회원이 Threads 설정에서 ThreadPilot의 접근 권한을 제거하거나 서비스에서 연결을 해제하면, 운영사는 해당 토큰을 즉시 폐기하고 더 이상 게시·조회 요청을 보내지 않습니다.
  • 삭제 — Meta를 통해 들어오는 데이터 삭제 요청도 동일하게 처리하며, 처리 결과와 확인 코드를 안내합니다. 자세한 내용은 데이터 삭제 요청 안내를 참고하세요.

8.쿠키와 세션

서비스는 로그인 상태를 유지하기 위해 필수 쿠키만 사용합니다.

  • 이름 — tp_session (로그인 세션, 30일)
  • 내용 — 회원 식별자와 만료 시각을 담은 서명된 토큰. 비밀번호나 Threads 토큰은 담기지 않습니다.
  • 속성 — HttpOnly, Secure, SameSite=Lax
  • 사용 목적 — 로그인 유지, 요청 위조(CSRF) 방지

운영사는 광고·추적·분석 목적의 쿠키를 사용하지 않습니다. 회원은 브라우저 설정에서 쿠키를 삭제하거나 차단할 수 있으나, 이 경우 로그인이 유지되지 않습니다.

  • 정정 — 이름·업체명·업종 등은 설정 화면에서 직접 수정할 수 있습니다.

  • 처리 정지 — 자동 발행 중지, 연결 해제, 수집 정지를 요청할 수 있습니다.
  • 동의 철회 — Threads 계정 연결에 대한 동의를 언제든지 철회할 수 있습니다.

10.안전성 확보 조치

  • 암호화 — Threads 액세스 토큰과 결제 빌링키는 AES-256-GCM으로 암호화해 저장하며 암호화 키는 코드·데이터베이스에 두지 않습니다. 비밀번호는 PBKDF2-SHA256으로 단방향 해시하여 저장합니다.
  • 전송 구간 보호 — 모든 통신은 HTTPS로 암호화합니다.
  • 접근 통제 — 세션은 서명된 토큰으로 검증하며, 회원은 자신의 데이터에만 접근할 수 있습니다. 운영자도 토큰 원문을 볼 수 없습니다.
  • 최소 권한 — Threads 권한은 발행·댓글 기능에 필요한 범위만 요청합니다.
